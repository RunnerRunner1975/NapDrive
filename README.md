# NapDrive prototype

Upload these files to a static HTTPS host such as GitHub Pages. Open the resulting HTTPS address in Safari and use Share → Add to Home Screen.

The prototype uses device geolocation, Nominatim for UK destination lookup, OSRM for driving routes, Leaflet for the map, and Apple's unified Maps URL format for a multi-stop handoff.

It is a proof of concept, not production navigation software. Public routing/geocoding services have usage limits. A production version should use a proper backend and native iOS/CarPlay navigation.
